# 考前建築所：2026-11-05 更新與驗收

## 問題與設計

原有網站已有 13 科 120 主題、925 道歷屆題與 34 套段考方案。這次優先解決學生進站後不知道讀什麼、不同版本章序難對應、讀過卻沒有確認理解，以及考前範圍超出可用時間等問題。

以「今天一小步 → 圖解短課 → 自選考程 → 錯題回想」組成工作桌。首頁主行動與行動版底部導覽都可直達 `/study-studio/`；原有大學建築之路留在主選單。

基準由程式直接載入既有 `allSubjects` 得到 120 個主題，30 / 120 = 25%。這是新增教學頁單元數比例；新短課約 10 分鐘、篇幅小於完整章節，**不宣稱全文字數或所有教材覆蓋率增加 25%**。

專業與共同考科有 24 個短課，自然、社會與實務另有 6 個段考延伸短課。題目為本站原創，與官方歷屆題分開標示。

## 課綱研究與版本界線

2026-11-05 查核以下官方入口與專業考綱：

- [116 統測考試大綱](https://www.tcte.edu.tw/doc/116Range_4y/)
- [專一考綱](https://www.tcte.edu.tw/doc/116Range_4y/116-4y-06-1-range.pdf)：基礎工程力學、材料與試驗。
- [專二考綱](https://www.tcte.edu.tw/doc/116Range_4y/116-4y-06-2-range.pdf)：測量實習、製圖實習。
- [國教院技術型高中課綱入口](https://stv.naer.edu.tw/teaching/course_outline.jsp?lvtype=B)：土木與建築群。

以共同知識範圍支援各版本，提供出版社／冊次文字備註、老師範圍與 150 個可選項（120 原主題＋30 短課）。**尚未完成所有出版社逐冊逐頁查證**，不宣稱全版本完全覆蓋；課堂考試仍以任課教師公告為準。

頂標是準備目標，探索值與兩題檢核不換算統測級距。頁面串連原有完整章節、歷屆整卷與官方制度說明，供學生確認遷移與計時作答能力。

## 學習行為與資料

- 首次答對每題 10 點，之後同題重答不增加探索值；答錯不扣點。
- 錯誤答案進入複習清單，重答正確後移出當日待修正。
- 跨日連續答對依次排 1、3、7、14 天回想；同日重答不延長間隔。
- 知識磚僅表示兩題初次檢核完成，不稱為完整精熟。
- 學科圖表顯示實際已答、最近答對與待修正題數，未答題保留空白，不造假成績或同儕排名。
- 考程每單元先估 10 分鐘，標示完整章節可能需要更多時段。超出考前容量會警示；考試當天不當成可用讀書日。
- 考程開始日固定保存，避免每次開頁都自動順延。
- 資料使用獨立的 `arch-study-studio-v1` 瀏覽器儲存，不覆寫既有闖關及歷屆錯題紀錄；支援文字考程匯出。尚無跨裝置同步。

## 迭代與驗收

第一輪以官方考綱核對專業範圍、獨立重算數字題；修正向量夾角選項須包含反向平行 180° 的邊界。第二輪檢查排程與保存，修正開始日漂移。第三輪以 **Codex 內建瀏覽器**操作本機開發站，發現並修正原有手機頂部導覽被裁切：390px 時頁面寬原為 416px，修正後不超過視窗。

這是瀏覽器尺寸模擬，不冒充 iOS／Android 實機測試。日期欄位經原生鍵盤操作確認會更新；內建自動化的 `fill` 對日期沒有觸發變更事件時，使用方向鍵驗證原生事件，未以程式直接改動網頁狀態。

自動檢查：`pnpm validate:content`、既有 V6/V7/70x7 檢查、39 項學習流程檢查、TypeScript、ESLint、正式靜態輸出與既有題庫分片檢查。`node scripts/validate-study-studio.mjs` 另驗證真實基準、30 頁內容結構、25 組獨立數值核對、間隔排程與容量邊界；加 `--built` 檢查31頁輸出與 `/Arch` 路徑。ESLint 原有3項未使用變數警告，不涉及本次功能。

GitHub Actions 在部署前也執行新增驗證。部署後應以相同 Codex 內建瀏覽器開啟正式 `/Arch/study-studio/`、操作一個短課並確認靜態資源與連結。
