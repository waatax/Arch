# 閱讀格式與知識校正 10.1.0

日期：2026-11-07。基準：已發布的10.0.0。

## 格式與閱讀

- 共享教學閱讀區與61份學期講義使用相同紙色、墨色、重點色及分隔規則，隨淺色、深色、暖色與OLED主題切換。
- 知識、原題、示範與遷移練習有清楚分區；題型目錄補上年度與題號，避免相同題型名稱難以辨認。
- 講義增加單元編號、考前七／三／一天安排、連結與自測層次。保留全部265單元、530道自測及2,336個精確教學連結。
- 正文以相對字級呈現；公式、粗體與原題底線經共同文字元件排版，表格使用caption及欄標題。
- 手機寬表與工程圖保留可讀大小，提供局部橫向捲動；平板／桌機展開適當欄數。圖說與標籤不再使用10–11px小字。
- 移除面向學生的開發增幅百分比提示，改為學習任務及理解檢查。自評提示說明本次頁面的狀態，未宣稱永久保存。
- 修正120個教學頁的重複`traps`錨點；每次引用圖解都分配獨立SVG標題與箭頭識別碼，避免講義多個單元引用同題時互相指錯。

## 驗證範圍

24組來源檢查與6組靜態輸出檢查通過，另通過TypeScript、lint及338頁正式建置。925題原有知識、逐步解析及遷移題完整性閘門保留；未用此次格式調整宣稱重新人工審定每一句文字。

新增`validate:knowledge-accuracy`核對科學修正案例、12格衰減數值及四種閱讀主題對比。掃描13科的250個公式欄位，其中35個有明確數學定界符的LaTeX區塊通過KaTeX語法驗證；這不是250個公式的全部數學證明。共享閱讀區的正文、次要文字與重點色對紙色對比均達4.5:1以上，未將此擴大宣稱為全站WCAG認證。
