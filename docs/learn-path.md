# 闖關學習（`/learn`）：建築科三年六學期全科地圖

Duolingo 式的每日闖關：每關 5 題，答錯的題目會在關卡最後再出現一次。整條路徑依 108 課綱排好，從高一上排到高三下，涵蓋部定一般科目、部定專業與實習科目、專業製圖技能領域，以及高三的校訂科目示例。

## 排課依據

| 類別 | 依據 | 畫面標示 |
| --- | --- | --- |

| 專業製圖技能領域（建築製圖實習、施工圖實習） | 同手冊表 2-3「技能領域建議授課年段」 | 官方建議學期 |

| 高三校訂科目 | 技高常見規劃，包括專題實作、統測總複習、丙級證照、職安法規 | 校訂科目示例 |

表 2-2、2-3 的官方配置：

- 高一上：土木建築工程與技術概論 2、測量實習 4、製圖實習 4

各專業與實習單元的課綱對應，標註的是手冊「學習內容」代碼，例如「土建-專-力學-F：桁架」。

## 遊戲機制

依 README 的內容原則，這裡不做排行榜、扣點或焦慮式連勝。

- **路徑**：每個單元依序是「新觀念 → 練習 → 寶箱 → 單元挑戰」。新觀念關開頭會先顯示指南重點，單元挑戰的 XP 為 1.5 倍。
- **跳級測驗**：題目從前面各單元抽出，首答答對 80% 以上，就把前面的關卡標為完成。
- **XP**：每題首答正確得 2 XP，完美通關再加 5 XP。
- **連續學習**：每天完成一關就延續連續天數。漏掉一天時，會自動使用一張「休息日卡」，卡片用寶箱與每日任務得到的磚塊兌換。連續中斷時只是重新計算，不扣 XP。
- **個人週賽**：等級依本週 XP 計算，分為紅磚、清水模、鋼骨、帷幕、地標。只跟自己的上週比較。
- **每日任務**：每天固定三個，依日期決定，完成後可領取磚塊。
- **錯題本**：首答答錯的題目會自動收錄，在 `/learn/review` 答對後移出。
- **成就**：共 14 枚，例如完美通關、連續學習 7 天、學期封頂。
- 學習紀錄存在瀏覽器的 localStorage（`arch-learn-path-v1`），不會上傳。

## 題庫寫法（給老師與維護者）

題庫在 `apps/web/src/data/learnPath/content/*.ts`，每門課一段純文字，一行一筆：

```text
## 單元標題 @ 課綱學習內容 => subject/topic
- 指南重點（可多行）
Q 題幹 | 正解 | 誘答 | 誘答 | 誘答 // 解析
T 敘述 | O（或 X） // 解析
M 題幹 :: 左 => 右 ; 左 => 右 ; 左 => 右 // 解析
S 題幹 :: 第一步 >> 第二步 >> 第三步 // 解析
N 題幹 | 數值 | 單位（沒有寫 -） | 容許誤差 // 解析
```

- 選擇題的第一個選項永遠是正解，執行時才洗牌。
- 數學式沿用全站 `$...$`。
- 英文句子寫成 `{{English}}`，學生可以點擊朗讀。
- `=> subject/topic` 會在單元上顯示「深入教學頁」連結。
- 課程清單（學期、學分、類別、排課依據）在 `catalog.ts`。

## 品質閘門

`pnpm validate:learn` 已併入 `validate:content`，部署時會自動執行。它會檢查：

- 表 2-2、2-3 的科目、學期與學分是否正確。部定專業合計 10 學分，部定實習合計 36 學分。
- 一般科目各領域都有開課，數學 C 只排在第一、二學年。
- 每門課的單元數：核心科目至少 4 個，其他至少 3 個。每單元至少 6 題，指南至少 2 條。
- 題型至少 3 種，有解析的題目至少 80%。同一門課內題幹不可重複。
- 選擇題的正解不可長達誘答的兩倍以上，避免學生「挑最長的就對」。誘答應寫成長度相近的合理迷思。
- 所有 `$...$` 都要能被 KaTeX 解析，資料中不得有吃掉反斜線的控制字元。
- 教學頁連結都必須存在。
- 引擎回歸測試，包括休息日卡、跨月日期、關卡切分、分數與全形數字輸入、XP 計算。
