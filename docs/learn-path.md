# 闖關學習（`/learn`）：建築科三年六學期全科地圖

Duolingo 式的每日闖關：每關 5 題，答錯的題目會在關卡最後再出現一次。整條路徑依 108 課綱排好，從高一上排到高三下，涵蓋部定一般科目、部定專業與實習科目、專業製圖技能領域，以及高三的校訂科目示例。

## 排課依據

| 類別 | 依據 | 畫面標示 |
| --- | --- | --- |
| 部定專業科目、部定實習科目 | 國家教育研究院《土木與建築群課程手冊》（111 年 7 月更新）表 2-2「部定必修科目建議授課年段」 | 官方建議學期 |
| 專業製圖技能領域（建築製圖實習、施工圖實習） | 同手冊表 2-3「技能領域建議授課年段」 | 官方建議學期 |
| 部定一般科目 | 同手冊表 2-1 的學分規定。哪一學期上哪一科由各校課程計畫決定 | 示例排課 |
| 高三校訂科目 | 技高常見規劃，包括專題實作、統測總複習、丙級證照、職安法規 | 校訂科目示例 |

表 2-2、2-3 的官方配置：

- 高一上：土木建築工程與技術概論 2、測量實習 4、製圖實習 4
- 高一下：構造與施工法 2、測量實習 4、製圖實習 4
- 高二上、高二下，每學期各：基礎工程力學 3、材料與試驗 2、營建技術實習 3、設計與技術實習 2、電腦輔助製圖實習 3
- 技能領域：建築製圖實習 3 在高二上，施工圖實習 3 在高二下

各專業與實習單元的課綱對應，標註的是手冊「學習內容」代碼，例如「土建-專-力學-F：桁架」。

## 遊戲機制

依 README 的內容原則，這裡不做排行榜、扣點或焦慮式連勝。

- **路徑**：每個單元依序是「新觀念 → 練習 → 寶箱 → 單元挑戰」。新觀念關開頭會先顯示指南重點，單元挑戰的 XP 為 1.5 倍。
- **跳級測驗**：題目從前面各單元抽出，首答答對 80% 以上，就把前面的關卡標為完成。
- **XP**：每題首答正確得 2 XP，完美通關再加 5 XP。
- **連續學習**：每天完成一關就延續連續天數。漏掉一天時，會自動使用一張「休息日卡」，卡片用寶箱與每日任務得到的磚塊兌換。連續中斷時只是重新計算，不扣 XP。
- **個人週賽**：等級依本週 XP 計算，分為紅磚、清水模、鋼骨、帷幕、地標。只跟自己的上週比較。
- **每日任務**：每天固定三個，依日期決定，完成後可領取磚塊。
- **錯題本**：首答答錯的題目會自動收錄，在 `/learn/review` 答對後移出。
- **成就**：共 14 枚，例如完美通關、連續學習 7 天、學期封頂。
- 學習紀錄存在瀏覽器的 localStorage（`arch-learn-path-v1`），不會上傳。

## 題庫寫法（給老師與維護者）

題庫在 `apps/web/src/data/learnPath/content/*.ts`，每門課一段純文字，一行一筆：

```text
## 單元標題 @ 課綱學習內容 => subject/topic
- 指南重點（可多行）
Q 題幹 | 正解 | 誘答 | 誘答 | 誘答 // 解析
T 敘述 | O（或 X） // 解析
M 題幹 :: 左 => 右 ; 左 => 右 ; 左 => 右 // 解析
S 題幹 :: 第一步 >> 第二步 >> 第三步 // 解析
N 題幹 | 數值 | 單位（沒有寫 -） | 容許誤差 // 解析
```

- 選擇題的第一個選項永遠是正解，執行時才洗牌。
- 數學式沿用全站 `$...$`。
- 英文句子寫成 `{{English}}`，學生可以點擊朗讀。
- `=> subject/topic` 會在單元上顯示「深入教學頁」連結。
- 課程清單（學期、學分、類別、排課依據）在 `catalog.ts`。

## 品質閘門

`pnpm validate:learn` 已併入 `validate:content`，部署時會自動執行。它會檢查：

- 表 2-2、2-3 的科目、學期與學分是否正確。部定專業合計 10 學分，部定實習合計 36 學分。
- 一般科目各領域都有開課，數學 C 只排在第一、二學年。
- 每門課的單元數：核心科目至少 4 個，其他至少 3 個。每單元至少 6 題，指南至少 2 條。
- 題型至少 3 種，有解析的題目至少 80%。同一門課內題幹不可重複。
- 選擇題的正解不可長達誘答的兩倍以上，避免學生「挑最長的就對」。誘答應寫成長度相近的合理迷思。
- 所有 `$...$` 都要能被 KaTeX 解析，資料中不得有吃掉反斜線的控制字元。
- 教學頁連結都必須存在。
- 引擎回歸測試，包括休息日卡、跨月日期、關卡切分、分數與全形數字輸入、XP 計算。

## 統測對標檢定（低標／中標／高標）

每門與統測相關的課程（國文 1～6、英文 1～6、數學 C 1～4 與總複習、測量、製圖、力學、材料、專一／專二總複習），路徑底部都有一張「統測對標檢定」：

- **題目**：歷屆統測真題，共 918 題次。高一到高二是 111～114 年中屬於該課範圍的題目，每次抽 20 題；高三是整份 114 或 115 年原卷模擬。題組整組出題。
- **門檻**：測驗中心 D3 報表公布每題五個能力組（各 20% 考生）的答對率。低標、中標、高標分別是第 25、50、75 百分位考生在這次抽到的題目上的預期答對率，對應統測的後標、均標、前標。用 111～115 年選擇題整卷驗證，模型三標與官方三標平均相差 1.6 分，最大 4 分（validate:learn 會檢查）。
- **防背題**：一次檢定中至少 75% 是沒做過的題目，成績才更新徽章；其餘當練習。
- **統測能力儀表板**（/learn）：合併所有首答，估計每個考科的全體考生百分位與 80% 區間，再用最新年度三標換算預估分數。
- **五個等級**：低標、中標、高標、頂標、榜首級，分別是第 25、50、75、88、97 百分位。統測只公布前三標；頂標比照大考中心「第 88 百分位」的定義，榜首級取第 97 百分位。
- **頒發徽章**：答對率要過門檻，且能力估計至少有 70% 把握達到該等級（榜首級為 50%）。整卷模擬中，第 93 百分位考生約三分之二拿到頂標，第 50 百分位考生不會拿到高標以上（validate:learn 會檢查）。
- **獎勵**：首次達到低標、中標、高標、頂標、榜首級，分別得到 15、25、40、60、100 塊磚。
- **頂標特訓**：從題池挑出 10 題「鑑別題」，也就是前 20% 考生多半答對、全體答對率偏低的題目，依 (Pa − Pb) + 0.5 × (Pa − P) 排序。成績不更新徽章，但作答會納入能力儀表板。
- **每題回饋**：答題後顯示前 20%、中間 20% 與全體考生的答對率，並標示是頂標鑑別題還是基本分題。
- **弱點診斷**：結算時依主題彙整答錯題，以頂尖考生在這些題的答對率排序，連到對應教學頁。
- **整卷計時**：高三的整卷模擬顯示計時與配速。國文 90 分鐘，其餘 100 分鐘。
- **頂標特訓單元**：力學Ⅰ、力學Ⅱ、測量實習Ⅰ、數學 C 第 3 冊、第 4 冊，各有一個手寫多步驟計算單元，每題都附解析。

資料更新流程：

1. 從測驗中心「公告資料專區」下載各年 B1、D3 PDF，放進同一個資料夾，命名為 `{年}-B1.pdf`、`{年}-D3.pdf`。
2. 執行 `node scripts/import-tcte-opendata.mjs <資料夾>`，產生 `data/registry/tcte-item-stats.json`。113 年官方的五組答對率與全體答對率不一致，腳本會改用 3PL 模型重建，並標註 `bandSource: "3pl"`。
3. 執行 `pnpm build:learn-exam-bank`，重新產生 `apps/web/src/data/learnPath/generated/examBank.json`。

## 遊戲倫理設定

- **休息模式**：最多預先排 3 天，這幾天沒學習也不會中斷連續天數，且不消耗休息日卡。
- **震動回饋**：可以關閉，與音效開關分開。
