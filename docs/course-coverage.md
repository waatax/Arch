## 回推教材的主要缺口與補強

- 力學：以自由體圖、方向餘弦、零力桿、微分積分、孔洞負面積及最大應力公式，推導滑動／傾倒競爭、桁架、形心、梁及莫爾圓。新增原生向量教學示意。
- 材料：修正紅磚抗壓誤掛混凝土、鋼筋規格誤掛水泥等問題；補受壓面、平方單位、材料機理與規格辨識。
- 測量：坐標與間接距離不再掛在水準章；補同站消去儀器高、天頂距 cot、傾斜視距兩次投影及閉合差取整。
- 製圖：補尺度與實長平方關係、折圖檢索、投影象限、剖面與尺寸標註；維持原題圖可核對。
- 數學 C：15 章各至少有一種實題示範。修復若干根號、積分、增廣矩陣 OCR，避免靠猜圖解題。
- 語文：補近義字、對話語用、克漏字銜接、篇章證據與圖表閱讀；題組文章一併呈現，避免缺上下文作答。

## 答題與驗證原則

112 專二第 27 題的 CD 表示 C 或 D 任一均接受；章節與模擬考介面均維持單選。送分題依官方規則計入模考分數，不作為熟練度或 XP 證據。重複點選同一題的正解，不重複發放 XP（同次頁面工作階段）。模擬考分片同步所有已編寫解析，並以 9.2.0 版本分片避免混入舊資料。

執行 `pnpm validate:content`、`pnpm validate:exam-teaching`。檢查涵蓋來源隔離、唯一 ID、真實路由、原圖存在、題組文章、解法結構、數式重算及官方替代答案判定。另從原表重新篩選週六可搭車次、重算颱風年度與月份次數，並檢查桁架全部節點的二軸平衡。`node scripts/validate-exam-teaching.mjs --built` 確認靜態輸出含新精講與正確分片。自動結構檢查不能替代教育專業的逐題審查。
