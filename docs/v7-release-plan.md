# Arch V7 改版與上線計畫

## 產品判斷

V6 已具備完整內容、題庫、案例、PWA 與 Android 外殼，主要問題不再是內容不足，而是首頁同時展示太多能力，初次使用者難以判斷下一步。V7 將首頁從「功能型錄」改為「任務分流」。

## V7.0 上線範圍

- 首頁建立三條清楚路徑：從零開始、考前衝刺、建築素養。
- 全新 editorial blueprint 視覺系統：大字級、工程格線、藍圖卡與珊瑚行動色。
- 手機優先的單欄決策流程與 48px 以上觸控目標。
- 將 86 章、925 題、8 案例轉為可信但不搶焦點的證據。
- 保留深色模式、reduced-motion、ArchLite、靜態匯出與本機資料隱私。

## 後續迭代
