# 響應式與手機品質基線

更新：2026-08-03

## 支援寬度

- 320–374 px：小型手機，導覽控制不重疊，主要操作維持完整。
- 375–430 px：主要手機基準，圖解、題目、公式與案例任務皆可完成。
- 431–767 px：大型手機與直向小平板。
- 768–1023 px：平板雙欄布局。
- 1024 px 以上：桌面多欄布局。

## 全站契約

- 頁面不得出現非預期的水平捲軸；寬表格與長公式只能在自身容器中橫向捲動。
- 主要按鈕與行動版導覽目標高度至少 44 px。
- 首頁主要 CTA 在手機為滿寬，避免文字擠壓或形成過小點擊區。
- 章節標題、雙語詞彙、公式、URL 與解題步驟必須可以換行或安全捲動。
- 章節表格在手機顯示「左右滑動」提示，且容器可用鍵盤取得焦點。
- OpenAI 教學圖解依 320、375、430、768 px 自動切換正方形、4:3、16:9 展示框。
- 案例六鏡頭在手機使用橫向 snap 分頁，避免六個按鈕堆疊占滿首屏。
- 上一章、科目目錄、下一章在手機均為完整觸控卡。
- 支援安全區 `env(safe-area-inset-bottom)`、200% 文字放大與 `prefers-reduced-motion`。

## 發布前抽測路徑

1. `/`：首頁標題、兩個 CTA、案例卡與全部科目卡。
2. `/curriculum`：六個課程群組與長科目名稱。
3. `/subjects/mechanics/beam`：公式、寬表格、圖解與多步驟解題。
4. `/subjects/math-c/trigonometry`：數學符號、公式和建築測高圖解。
5. `/subjects/materials/concrete`：多欄材料表與長篇試驗步驟。
6. `/cases/taichung-national-theater`：案例標籤、鏡頭切換、概念橋與實作任務。

## 自動檢查

每次修改至少執行：

```bash
pnpm validate:content
pnpm lint
pnpm build
```

視覺發布閘門仍應在具備瀏覽器連線的環境擷取 320、375、430、768、1440 px 截圖，確認沒有裁切、遮擋或意外換行。
