# V7 深入淺出教學研究與七輪逐頁優化

## 改版目標

同一份教材從生活直覺出發，經圖像、語言、應用與逐步示範，自然進入技高正式課綱與統測題型。不以年齡標籤拆成多版，也不降低正式知識精度。

## 研究依據

- 國家教育研究院土木與建築群 108 課綱強調學生主體、實作導向、跨科技能、務實致用、專題實作及職涯能力。
- 技專校院入學測驗中心 115 考試科目與大綱確認土建群專一為基礎工程力學、材料與試驗，專二為測量實習、製圖實習；歷屆答案僅適用該年度，教材應以最新課綱為準。
- EEF worked examples 研究建議完整示範、思考外顯、交替練習與逐步撤除提示，降低初學者工作記憶負荷。
- CAST UDL 建議同一概念提供文字、符號、圖像及可操作表徵，並澄清專業字彙和數學符號。

## 七輪逐頁優化

1. 先備與白話：以身邊可觀察現象重述主題，不先丟公式。
2. 概念網：把前三個核心觀念連成條件—機制—結果。
3. 深度推理：示範題每一步補上「為什麼」與驗證方法。
4. 多重表徵：加入一致的向量圖示、主題圖、文字、表格與公式。
5. 錯誤診斷：把錯誤定位到條件、觀念、程序、單位或過度推論。
6. 真題遷移：補題意重述、線索、核心規則、正解依據、干擾項檢查及變式。
7. 完整精熟：以五項可觀察成果檢查能否解釋、操作、驗算、訂正與遷移。

## 完整度定義

每頁必須有至少三個正式觀念、一題示範題、自主練習、專屬主題圖、三個應用任務、課綱錨點、五項精熟證據、七輪深化及可追溯來源。`validate:v7-teaching` 將上述要求變成 CI 阻擋條件。
