# Arch V5 Implementation Plan

> 狀態基準：2026-08-04  
> 規格來源：[`../Arch-v5.md`](../Arch-v5.md)  
> 原則：先完成七輪研究與逐題覆蓋規劃，再依「歷屆題 → 技能 → 教學 → 練習」順序實作。

## V5 優先執行序

1. 建立 111–115 學年度官方題本、答案、確認說明與查核日期 registry。
2. 定義逐題 `ExamQuestionMap` schema、狀態與覆蓋率 validator。
3. 完成專一、專二十份試卷的題號級拆解，不以考科名稱代替逐題分析。
4. 反向映射 86 個既有主題，列出 `covered`、`partial`、`missing`、`source-conflict`。
5. 優先補全 `missing`，並按國中畢業程度重寫先備、白話概念、公式與示範。
6. 完成題庫頁、主題頁雙向連結、視覺與無障礙修正。
7. 由 AI Agent 交叉比對官方題本、答案、確認說明與 Arch 內容並直接校正，再執行內容、斷鏈、lint、typecheck 與 build。

## 2. P0：基線與治理（先做，1–2 週）

- [ ] 建立 `content/skills`、`content/questions`、`content/cases` 與 JSON Schema。
- [x] 建立 SQLite 初始 schema（`data/schema/arch-v4.sql`）。
- [ ] 建立 `source.yml` schema、URL allowlist、授權狀態與年度複查規則。
- [ ] 建立 question/case validator；錯誤內容進 quarantine，不進正式 bundle。
- [x] 建立課程覆蓋 registry 與 115 學年度專一／專二考綱對照；細粒度 skill crosswalk 留待資料 bundle 階段。
- [ ] 補齊 CODEOWNERS、內容審稿、錯誤通報、下架與 CLA 流程。
- [ ] CI 執行 lint、typecheck、test、schema validation、broken-link 與靜態建置。

驗收：從一份合法的官方或自編 seed 內容，可重建 SQLite bundle 與 manifest；每筆資料可追溯來源及版本。

## 3. P1：公開學習垂直切片（2–3 週）

首條切片採「材料與試驗／混凝土」：真實案例提問 → worked example → 提取練習 → 詳解 → 錯因 → 下一個任務。

- [ ] 統一 `SubjectData` 與內容 schema，移除 `practice`/`practices` 雙軌。
- [ ] 題目支援多技能權重、難度、來源、頁碼、適用學年度與授權狀態。
- [ ] 建立搜尋索引與免登入練習頁；所有公開頁均可靜態匯出。
- [ ] 案例頁以六鏡頭呈現：場域、空間、結構、材料、環境、社會。
- [ ] 每個案例至少連回 2 個考點、1 個動手任務、1 組跨專業角色。
- [ ] 建立 100 條真實學生問題的搜尋可達率測試集。

驗收：未登入學生能在 10 分鐘內完成一個有來源的完整學習回合；核心流程無網路 API 亦可運作。

## 4. P2：本機學習教練（2–3 週）

- [ ] 在 `packages/domain` 實作 mastery v2、半衰期間隔、推薦器與錯因映射的純函式。
- [ ] 以 IndexedDB 起步、OPFS/SQLite 為大量題庫層；不得把學生資料寫入 repository。
- [ ] Today 任務遵守 5–20 分鐘預算，混合新學、複習、遷移與興趣任務。
- [ ] 連續挫折時縮小任務、提供 worked example，不顯示排名或羞辱性文案。
- [ ] 提供個人資料匯出、匯入、清除與 schema migration。

驗收：固定事件輸入產生固定的明日任務；離線可作答、看詳解、記錯因並排入複習。

## 5. P3：內容規模化與台灣案例（3–4 週）

- [ ] 專一、專二最小內容包完成率先達 60%，再擴充共同科目。
- [ ] 12 個首發案例先完成 metadata 與 fact-check，再逐案補圖解及任務。
- [ ] 建立台中近場三部曲現地觀察單與建築護照；不以打卡或連勝作為獎勵。
- [ ] 興趣設計採「好奇問題→選擇→動手→解釋取捨→留下作品證據」。
- [ ] 讓學生看見建築師以外的結構、測量、BIM、材料、營造與永續職涯。

驗收：案例不是相簿；每案可產出一項可放進學習歷程的草圖、量測、模型或短反思。

## 6. P4：升學與作品歷程（2–3 週）

- [ ] 以年度快照管理四技二專招生、甄選、技優、證照與校系資料。
- [ ] 所有升學頁顯示學年度、官方來源、查核日、下次查核日與變動提示。
- [ ] 模考缺口連回技能與練習；作品 rubric 連回觀察、圖面、構造、材料與反思證據。
- [ ] 不預測或保證錄取；不代寫、不代畫、不偽造學習歷程。

驗收：學生可從目標校系建立可調整時程，並匯出一份含來源與能力證據的準備清單。

## 7. 橫切品質閘門

- WCAG 2.2 AA；全流程可用鍵盤，動畫遵守 `prefers-reduced-motion`。
- 375、768、1440 px 截圖檢查；文字放大 200% 不截斷主要操作。
- 首屏不依賴遠端字體才能閱讀；圖片有權利狀態、替代文字與尺寸預算。
- 嚴重事實錯誤 48 小時內修正；到期事實自動顯示待複查，不靜默沿用。
- 學習遙測採最小化、去識別化且可退出；不收集作品、反思或逐題內容。
